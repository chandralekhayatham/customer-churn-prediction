# customer-churn-prediction
End-to-end Machine Learning project to predict customer churn using classification models, feature engineering, and business insights.
# 📊 Customer Churn Prediction Model

## 📌 Overview

This project predicts whether a customer is likely to churn (leave a service) using Machine Learning.

Customer churn prediction helps businesses reduce customer loss, improve retention strategies, and increase revenue.

---

## 🚀 Features

* Built classification models using Logistic Regression and Random Forest
* Handled imbalanced data using appropriate techniques
* Performed feature engineering and preprocessing
* Evaluated models using precision, recall, F1-score, and ROC-AUC
* Generated business insights for customer retention

---

## 🛠️ Tech Stack

Python, Pandas, Scikit-learn, Matplotlib, Seaborn

---

## 📂 Workflow

Customer Data → Preprocessing → Feature Engineering → Model Training → Prediction → Business Insights

---

## 📊 Results

* Identified customers at high risk of churn
* Improved prediction performance using ensemble models
* Provided actionable insights for retention strategies

---

## 💡 Business Impact

* Helps companies reduce customer loss
* Enables targeted marketing campaigns
* Improves customer satisfaction
